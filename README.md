Local Malware Device
Title: Build a Local Device device data hacking
Description: Implement a local agent (desktop/mobile) that performs tasks like deleting a
specified file or folder only when explicitly authorized, taking screenshots, capturing photos
using a connected webcam , recording audio/video for a time , and writing periodic device
location snapshots to a local location.json file. Also implement a local device info reporter
(RAM, available storage, device name, MAC addresses)
Learning outcomes: file I/O, media capture APIs, device info enumeration.
